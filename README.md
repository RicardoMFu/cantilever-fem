# Cantilever FEM

二维悬臂梁的教学实现：Q4、平面应变、2×2高斯积分，比较线弹性与J2弹塑性。
几何20m×1m，厚度1m；左端固定，右端只约束竖向位移，水平自由。

## 运行

```sh
python3 -m pip install -r requirements.txt
python3 checks.py
python3 linear.py
python3 run.py
```

`run.py`运行8×2、16×4、32×8三套网格的50步位移加载，结果写入`results/`。
已提交结果可直接检查；重新运行不需要有限元软件。

## 代码结构

| 文件 | 职责 |
|---|---|
| `linear.py` | 中文逐步注释的线弹性手算对应程序 |
| `material.py` | 批量三维J2径向返回、一致切线；不修改输入状态 |
| `fem.py` | 网格、B矩阵、稀疏组装、Newton与线搜索、状态提交 |
| `run.py` | 三网格实验、应力外推、图和结果保存 |
| `checks.py` | 切线差分、屈服、塑性体积不变、状态与弹性基准验证 |
| `report/` | 完整PDF、可独立编译的LaTeX与所需配图和表格 |

## 模型与参数

- 单位m、N、Pa；E=210GPa，ν=0.3。小应变、线性几何，不包含大变形。
- 原题端位移0.1m。教学塑性扩展至0.5m，每步0.01m。
- 新增假设：初始屈服应力250MPa，线性各向同性硬化H=1GPa。不是材料试验标定结果。
- H是屈服应力对等效塑性应变的斜率；单轴塑性段总应变切线为EH/(E+H)。
- 塑性应变与等效塑性应变是求解中演化的状态，不是额外给定材料常数。
- 工程剪应变用于B矩阵；材料函数输入三维应变张量（剪应变除以2）。
- 平面应变限制总eps_zz=0，但保留sigma_zz、plastic_eps_zz。不会增加节点自由度。
- 每次Newton试算从上一收敛步材料状态计算，仅平衡收敛后提交状态。
- 相对自由残差容限1e-8，最多35次Newton迭代；失败立即报错，不输出伪收敛结果。
- 稀疏方程用SciPy的直接求解器；不是调用有限元库。

## 当前结果

0.1m下三网格均保持弹性，与原线弹性反力一致。0.5m下：

| 网格 | 反力大小/kN | 最大等效塑性应变 | 首次发现塑性的加载位移/m |
|---|---:|---:|---:|
| 8×2 | 8407.268 | 0.001459 | 0.29 |
| 16×4 | 5103.920 | 0.000841 | 0.35 |
| 32×8 | 3801.481 | 0.000923 | 0.35 |

首次塑性是离散步/积分点上检测的值，未确定网格无关的屈服起点。
最细网格改为100步后，最终反力3801.586kN，相对50步变化0.0028%，见`results/step_refinement.json`。
Q4完全积分在细长梁弯曲中偏硬，粗网格反力尚有明显误差。
线性、非线性图中的应力显示方法见报告图注；非线性边界点使用高斯点应力双线性外推，不能临时重建无历史的边界材料点。
结果说明方法与代码行为，不是实际钢构件的强度评估。
